# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc] as its
Code of Conduct. All contributors, maintainers and community participants
are expected to follow it.

The full text is available at the link below; we incorporate it here by
reference rather than duplicating it so we always track the upstream
version.

- Covenant text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Translations: https://www.contributor-covenant.org/translations/

## Reporting

To report behavior that violates this Code of Conduct, contact the project
maintainer privately at **rafael@tonholo.dev**. Reports will be reviewed
and acted on confidentially.

## Scope

This Code of Conduct applies to all project spaces -- the GitHub repository
(issues, pull requests, discussions, code review), and any other channel
that represents the project.

## Enforcement

Maintainers will follow the Covenant's
[Enforcement Guidelines][cc-enforcement] when deciding on consequences for
any action they consider in violation, including warnings, temporary bans
and permanent bans where warranted.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[cc-enforcement]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
